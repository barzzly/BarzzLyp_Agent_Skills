# Retire one Minecraft mob pack

- Resolve target server from live panel inventory. Read source MythicMobs pack, ModelEngine blueprints, shared healthbar starts, Nexo glyphs, textures and font providers; pack name alone misses model IDs and numbered helper skills.
- Back up exact remote bytes outside loading trees before deletion. Derive model IDs from blueprint filenames, compare all other blueprints for shared IDs, and derive texture ownership from generated model JSON references; preserve textures used by any other model.
- Scan active plugin configuration for mob/model/helper references; exclude player data and inactive backups. Remove only pack-specific shared YAML mappings using source blocks and parsed semantic equality, preserving other IDs and custom-model-data numbers.
- Clean generated resource-pack ZIP entries and registration lists (`entries`, `overrides`, `providers`), plus exact on-disk generated counterparts. Reopen ZIPs, run CRC checks, assert absent target paths/references, and read back uploaded hashes. Never delete all ModelEngine resources or shared healthbar definitions.
- Preserve original backup manifest across interrupted attempts. Resume deletions idempotently: absent intended deletion is valid, changed writes must equal intended bytes or original backed-up hash; never replace original backup with partially modified state.
- Wings SFTP may reject `posix_rename`. For small backed-up config edits, validate staged bytes then write target and read back; for large ZIP replacement, validate staged hash, retain verified original locally, remove exact target, use standard rename, and read back final hash.
- Nexo 1.19.1 can retain removed glyphs in FontManager maps after `nexo reload all` and `nexo reload pack`, producing missing-texture warnings even when final ZIP providers are absent. Verify generated ZIP independently and report stale runtime glyph cache; do not restart without permission. ModelEngine reload can regenerate ZIPs concurrently, so verify final contents/CRC rather than comparing a pre-reload ZIP hash during regeneration.
- Inspect `server.properties` resource-pack URL and Nexo dispatch before claiming player delivery. Static externally hosted packs remain unchanged by server-side cleanup; report this boundary and do not rewrite unrelated delivery settings.
- Avoid `mythicmobs mobs stats` from console on 5.13.0: it casts sender to Player and throws ClassCastException. Use native list/info or inspected API instead. Preserve running state and do not use broad killall or server restart.
