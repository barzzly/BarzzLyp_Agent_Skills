# ShopGUIPlus live audit and narrow repair

- Audit live `shops/*.yml` plus `config.yml`. Detect duplicate YAML mapping keys before parsing: later `slot` and `clickActions` silently override earlier values. Treat `buyPrice`/`sellPrice: -1` as disabled sentinels, not arbitrage. Compare identical item definitions across categories, distinguish deliberate duplicates from conflicting prices, and choose price policy against related products before writing.
- Before live write, compare remote bytes to audited snapshot; back up each affected file. Upload only scoped YAML, read back exact bytes, execute native `shopguiplus:shop reload`, and require fresh `Loaded ... shops` with no `[ShopGUIPlus]` warning, slot conflict, or invalid-item message. Verify running server and unchanged JAR hash. If validation fails, restore backups, reload, and verify restored bytes.
- SmartSpawner may log a separate provider-already-registered warning on ShopGUIPlus reload. Attribute warnings by plugin; do not treat `[SmartSpawner]` warning as ShopGUIPlus YAML failure, but report if relevant.
- ShopGUIPlus loaded-item totals include balance specials; menu labels may count only item and enchantment entries. Recompute label after fixing invalid items. Recent live chain `material: CHAIN` failed loading; `IRON_CHAIN` loaded, with decoration item count increasing by one. Verify against actual runtime log, not only YAML parsing.
