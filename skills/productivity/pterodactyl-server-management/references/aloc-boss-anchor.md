# Aloc boss position anchor

- On NoeRPG, PUBLIC dungeon `aloc` uses world `DungeonAloc`; boss `alocTheDemonicMech` spawns at `(0,64,0)` via `plugins/NoeDungeon/dungeons/aloc/objectives.yml`.
- Its MythicMobs mob config is `plugins/MythicMobs/packs/BOSS_AlocTheDemonicMech/Mobs/alocTheDemonicMechMobs.yml`. It already has `MovementSpeed: 0.001`, `KnockbackResistance: 1`, and an `~onDamaged` velocity reset, yet external knockback can move it. Do NOT use rapid high-frequency teleport timers (e.g. `teleport @CasterSpawnLocation ~onTimer:5`): teleporting an entity every 0.25s desyncs server-side raytrace bounding boxes against client-predicted arrows, making bow hits fail / appear to have missing hitboxes, and causes ModelEngine subhitbox entities to lag/jitter. Instead, anchor bosses using zero AI velocity modifiers or low-frequency boundary resets (e.g. `~onTimer:100` only when displaced >3 blocks).
- **Projectile collision & "ghost hitbox" pitfalls in ModelEngine / MythicMobs**:
  - **Invincible helper/VFX mobs blocking arrows**: Skills spawning `bulletType=MOB` or helper dummies (such as `alocTheDemonicMechBaseDummy` or VFX projectiles) with `Invincible: true` and `Collidable: false` still register collision boxes in Paper's projectile raycast. When placed at or in front of the boss, incoming arrows strike the invincible helper and disappear/bounce with 0 damage. Replace mob bullets with pure particle/item display VFX or ensure dummy entities have no collision/hitbox bones.
  - **Spawn-phase Resistance gates**: Bosses given high-level Resistance (e.g. `potion{type=RESISTANCE;level=24}`) during intro/spawn remain completely immune if players shoot from beyond the trigger radius (`distance{d=<35}`). Ensure long-range bow attacks either trigger the combat phase or clear resistance on first damage.
  - **Silverfish base size vs Model dimensions**: Silverfish base entities measure only 0.4x0.3 blocks. Arrows hitting outside ModelEngine's configured subhitboxes (`b_` or `hi_`/`ob_`) pass through empty space. Ensure subhitboxes cover the full visual bounding box across animations.
- Backup exact remote bytes, edit only Aloc boss, verify readback; `mm reload` reloads MythicMobs without restarting server. Confirm completion in `logs/latest.log` and server state via resources. A reload does not demonstrate that an already-spawned boss adopted new timer behavior; verify during next boss spawn/attack and report that gap.
- Read `logs/latest.log` for console commands sent via Pterodactyl Client API because HTTP 204 only confirms command queued. Avoid spawning a duplicate boss into a live PUBLIC arena merely to test.

## Shared Arena Entry & Teleportation Safety
- **Auto-dismount sitting/mounted players**:
  - `Player.teleport()` in Bukkit / Paper returns `false` (refusing the teleport) when a player is sitting (e.g. GSit chairs, poses), riding a vehicle, or carrying passengers. Always execute `player.leaveVehicle()` and `player.eject()` before invoking `player.teleport(destination, TeleportCause.PLUGIN)` to enter dungeons or arenas.
- **Case-insensitive world containment checks**:
  - Session and region boundary containment checks must compare world names case-insensitively (`equalsIgnoreCase`), because Bukkit/Paper dimension keys and world aliases (e.g. `minecraft:dungeonaloc` vs `DungeonAloc`) can differ in casing and cause false out-of-bounds rejections.
