# HuskClaims wilderness flags

- Inspect live `plugins/HuskClaims/config.yml` for `database.type` before diagnosing current flags; when `MYSQL`, local SQLite file can be stale. Read `huskclaims_claim_worlds.data` from configured live DB (JSON on MySQL) and compare `wilderness_flags` per world against `claims.wilderness_rules`. Existing worlds retain flags independently of YAML. Add only missing `cloplib:block_place` on affected world(s), never replace whole list or touch claim records.
- Prefer live `/claimflags set <flag> <true/false>` from outside a claim for existing-world wilderness flags when authorized; do not restart a running server casually. If direct DB correction is necessary, stop gracefully first so cached world flags cannot overwrite change. Back up exact world row, use conditional update (`WHERE id=? AND data=?`), read back exact row, restart, confirm fresh HuskClaims enable and Paper `Done`, then read back DB flags again. Avoid touching unrelated worlds; config reload does not propagate wilderness flags into existing worlds.
- `redstone_actuate` governs piston/dispenser operation in wilderness, but missing wilderness flag cannot explain failures inside a player's claim. On NoeRPG it was absent from live `claims.wilderness_rules` and persisted wilderness flags; do not present this as sole root cause when claimed redstone also fails. Check plugin activation with live `/plugins`, not folder presence: `antiRedstoneClock` config folder existed while plugin was absent from active list. `RedstoneLimiter` was active with per-3-second thresholds (piston 8, dispenser 12), and console `redstonelimiter perblock` reported blocked events; correlate incident world/coordinates and single lever pulse versus clock with limiter evidence before changing it. LagFixer's RedstoneLimiter module was disabled. Preserve claim-specific protection, avoid casual restarts, and verify live behavior after any fix.
- Pterodactyl API behind Cloudflare needs `User-Agent: Mozilla/5.0`; urllib default user agent can get 403 despite valid key.
