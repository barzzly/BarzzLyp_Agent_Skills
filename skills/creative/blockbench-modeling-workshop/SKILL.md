# Blockbench modeling workshop

## Safe iterative work
- Inventory source models and hash originals before editing. Work on derivative copies in a separate workspace; do not deploy or publish vendor assets without authorization.
- Use real https://web.blockbench.net/ editor for import, editing, preview and export. Save actual .bbmodel artifacts, not scripts or logs alone.
- Distinguish Generic/ModelEngine animation from vanilla Java static item exports. Generic animation is not automatically compatible with vanilla item JSON.
- Keep experiment history in workspace journal. Record only verified reusable techniques in this skill; never store private endpoints, credentials, proprietary texture data, or operational paths here.

## Native app workflow (observed v5.1.6)
1. `new_tab('https://web.blockbench.net/'); wait_for_load()` then inspect `page_info()` and `typeof Codecs`. Do not assume named browser session retains its page. If subsequent calls land about:blank, perform navigation, import, edits and disk export within each single call.
2. Read local JSON in browser tool Python and invoke `Codecs.project.load(model, {path:'copy.bbmodel'})`. Inspect `Outliner.elements`, `Group.all`, `Texture.all`, `Animation.all`.
3. Wait for texture images to load before canvas edits. Preserve alpha with ImageData processing. Apply changed canvas via `texture.fromDataURL(canvas.toDataURL('image/png'))`. Inspect `texture.error` after reload.
4. Create native animation with `new Animation({name,length,loop,animators:{[group.uuid]:{name:group.name,type:'bone',keyframes}}}).add().select()`. Keyframes use channel, time, interpolation, data_points:[{x,y,z}]. Use linear rotation for continuous spins; inspect easing on scale/translation.
5. `Modes.options.animate.select(); Timeline.setTime(t); Animator.preview()` evaluates pose. Record group.mesh.position/rotation/scale at representative times. Transform evidence proves evaluation, not visual quality.
6. `Codecs.project.compile({raw:true,bitmaps:true,absolute_paths:false})` returns serializable model. Save with Python JSON, reimport, compare element/group/texture/animation counts and inspect errors. V5 exports `groups` separately from outliner; do not blindly handcraft old v4 layout.
7. Actual viewport image: `await new Promise(resolve => Preview.selected.screenshot({width:800,height:800},resolve))` returns data URL. Decode PNG locally. Camera presets available through `DefaultCameraPresets`, use `Preview.selected.loadAnglePreset(...)`. Frame subject tightly and inspect output; a successful PNG export can still show an unusably tiny subject.

## Verified browser pitfalls
- Check preview PNG alpha bounds immediately. A newly created project can export an empty MediaPreview image even when model counts/textures are valid; reimport saved project and capture Preview.selected as a tested recovery. Preserve failed image evidence and never treat export success as visual validation.
- Chunk large model JSON through multiple JS calls (for example 16k characters into an input string) before `Codecs.project.load`; a single large expression can fail with `Separator is found, but chunk is longer than limit`. Chunk compiled output back to Python too.
- Call `resize()` after switching camera projection. Native orthographic half-extents are viewport width/80 and height/80, divided by zoom: increasing zoom enlarges subject and can crop it severely. Frame from measured model extent, not guessed zoom above 1.
- Set projection BEFORE active camera position for reliable front/side captures. In v5.1.6 loadAnglePreset assigns camera position before setProjectionMode; first perspective-to-orthographic transition can leave requested position on inactive camera, producing oblique views or blank one-sided planes. Use setProjectionMode(true), resize, camera.position.set, controls.target.set, camera.zoom, camera.updateProjectionMatrix, controls.update, render; read back active position. Check PNG alpha bounds are nonempty before visual review.
- For a larger native render use `MediaPreview.loadAnglePreset(...)`, `MediaPreview.resize(width,height)`, `MediaPreview.controls.update()`, then `MediaPreview.screenshot(...)`. Screenshot width/height alone does not increase underlying render resolution.
- Diagnose framing with `screenshot({width,height,crop:false})`: default autoCrop recenters pixels, hiding camera-target errors, and never enlarges a small subject. For orthographic screenshots matching viewport dimensions, convert alpha-bounds center offset to camera-local units using pixels/(40*zoom), rotate that XY shift by camera.quaternion, and add it to BOTH camera.position and controls.target. Adjust zoom from occupied fraction, render again and assert nonempty unclipped bounds. Geometry bounds can include invisible/transparent VFX and produce severe under-framing; use actual rendered alpha for final fit.
- Preserve a fixed-camera comparison or world-transform evidence when fitting animation frames independently. Alpha-centered captures can make sinking or translating death poses look identical; fitted silhouettes alone cannot prove ground stability.
- Check `document.hidden` when Timeline.start barely advances. Hidden tabs can suspend requestAnimationFrame. Sampling Timeline.setTime plus Animator.preview verifies evaluated poses; a timer calling native Timeline.loop can verify advancement but must be labeled fallback, not uninterrupted visible UI playback.
- Counter-rotate pedal child bones around spindle origins opposite crank rotation to keep pedal platforms level; verify world quaternions after `Project.model_3d.updateMatrixWorld(true)` rather than local Euler values alone.

- After editing newly initialized Cube faces, use `Canvas.updateAll()` for native scene refresh. Calling `cube.preview_controller.updateAll()` without its element argument throws while reading an undefined mesh; never treat that interrupted batch as an export.
- Extract scalar face data (`uv`, texture UUID, rotation) rather than returning live CubeFace objects over CDP; native objects can contain cycles and fail with `Object reference chain is too long`. Scene mutations such as `scene.add(mesh)` also return cyclic objects; end evaluation with `void 0` or return a small scalar summary.
- Wrap awaited browser expressions in an invoked async function; this CDP evaluator rejects bare top-level `await`.
- Avoid assigning Python variables named `time` in browser batches: harness helper globals share that module name, and shadowing it breaks subsequent helpers with an AttributeError on time.monotonic. Use `t` for sample timestamps.
- Before animation evidence capture, enter animate mode, clear other animations' `playing` flags, select intended animation, explicitly set its `playing=true`, then call Timeline.setTime and Animator.preview. Native Animation.select() returns early if that animation is already selected; clearing playing then reselecting alone can leave every sample in rest pose. Assert a known nonzero evaluated bone rotation before rendering and include motion-range assertions in evidence checks.
- When checking preserved animations after native export, compare complete clip data excluding only verified UI-state fields such as `selected`. A changed selected clip does not change keyframes; diagnose exact diff before relaxing checks.
- Native preview/export may include animator entries without keyframes. Structural checks must distinguish keyed bones from empty entries rather than indexing `keyframes` unconditionally.
- A zero scale animation can evaluate to 0.00001 in native meshes. Treat this as native clamp, not exact zero; verify hidden effects visually too. Inspect scale channels before using a weapon pivot trajectory as visible grip evidence: a collapsed weapon still has a moving world origin.
- Inspect ancestor scale and translation before interpreting late torso keys as a visible death recovery. Body-level scale collapse can hide all descendants while local rotations continue. Capture fixed-camera frames before and after the collapse; do not auto-fit an invisible endpoint into a misleading giant image.

## Segmented page bends
- Approximate flexible paper with adjacent thin cubes under nested groups at each strip boundary; slice front UVs proportionally instead of duplicating whole artwork. Animate modest relative child rotations in addition to main hinge.
- Verify continuity using each native cube geometry bounding-box edge center transformed by mesh.matrixWorld; adjacent seam centers should agree within tolerance. Verify thickness/collision separately: matching center seams alone does not prove solid surfaces avoid overlap.
- Sample native transformed cuboid vertices against backing/stack with separating-axis tests (both boxes' face normals plus cross products). Positive projection gap proves separation at that sample only; document excluded intentional contacts and avoid claiming continuous clearance.

## Held weapons and pixel badges
- Inspect weapon position channels before asserting a fixed hand-local anchor. A weapon can remain a child of the arm while intentionally translating during attacks; compare native parent-local origins and visible hand contact separately. Matching first/last poses proves endpoint recovery only, not continuous two-handed contact.
- Give held weapons a dedicated grip child of the hand; keep barrel recoil below this anchor. Avoid large counter-rotations on a forearm sibling that visually disconnect the hold. Validate grip position in hand-local space across all clips and barrel world direction at fire time; matching UUIDs alone does not prove hand contact.
- Read parent chains from v5 `outliner`; `groups` metadata need not include a `parent` property. Compare reference boss hierarchies and attack/death keys without copying vendor geometry.
- Separate wrist presentation from finger opening: isolate hand meshes and render with camera position, target and up vector transformed by hand world transform. Compare finger local angles; a world-facing palm can look open while digits remain curled. Count named finger chains from hierarchy rather than guessing anatomy through occlusion.
- Sample Catmull-Rom segments even when adjacent endpoint keys match. Neighboring keys can produce small overshoot between identical values; equal endpoint rotations do not prove a constant hold.
- Keep receiver/mount static under grip while only barrel/muzzle translate for axial recoil; moving entire gun through fingers weakens contact even when parent chain is correct. Compare hand-local grip drift across sampled animations and inspect thumb opposition visually.
- For ground-contact previews, use a temporary thin box slab ending at Y=0 or a slightly elevated camera. A horizontal PlaneGeometry floor disappears edge-on in exact front/side views; a successful render may still show no ground. Keep temporary validation meshes outside model exports.
- For asymmetric kneeling, align the planted sole and opposite kneecap in native world coordinates, then inspect front and side with a temporary floor. Global minimum-Y correction alone can leave the intended support hovering. Side-view kneeling can still read standing from front; retain that critique rather than claiming full pose success.
- Distinguish an intentionally held death endpoint from a bad pose. Positive angles are not universally forward/back: inspect world vectors plus front/side renders. Ground bounding-box clearance does not prove balanced stance or genuine kneeling.
- Verify death timing against exact named clip and latest keys per channel. A once clip can have a static late interval in native sampling; identical late frames are not automatically a playback failure or reset. Sample earlier keyed times before diagnosing, and keep plugin runtime behavior unverified without game testing.
- For small RGBA pixel badges, measure exact source dimensions, alpha levels, opaque palette and padding before drawing. Never count RGB values under alpha=0 as visible colors. Composite transparent sources onto neutral/checkerboard before vision review; some image viewers expose hidden RGB.
- Verify specific glyph defects from opaque pixel rows before changing text. Visual review can misread an intact terminal stem; compare exact color/alpha coordinates and preserve correct lettering.
- Preserve native pixel dimensions for delivery; enlarge review previews with nearest-neighbor only. Use hand-placed pixel glyphs, stepped outlines, discrete highlight/shadow bands and binary alpha when reference uses no antialias. Read actual plugin font configuration rather than inferring Nexo/ItemsAdder from user shorthand.

## Java item JSON with external PNGs
- Import Java item/block JSON through `Codecs.java_block.load(model,{path:'assets/namespace/models/item.json'})`; do not treat it as BBModel project JSON. Resolve each texture `namespace:path` to `assets/namespace/textures/path.png`, chasing `#alias` and parent inheritance when present.
- Java `textures.particle` can reference a valid PNG without creating a separate native Texture entry. Bind actual `Texture.all` IDs, resolve their JSON aliases, and validate particle resources separately rather than assuming every JSON key has a native texture.
- On web, texture files are not automatically readable from local paths. Bind imported texture IDs explicitly using `Texture.all.find(t=>t.id===id).fromDataURL(dataURL)`; preserve face UUID mapping. Reimport exported JSON plus separated files to test the real deliverable.
- Preserve `.png.mcmeta` next to animated vertical strips. Check actual bitmap size versus square-frame size, frame count, frametime and alpha. Embedded BBModel and exported Java JSON/PNG are different deliverables; skeletal animations do not travel in vanilla Java item JSON.
- Apply external mcmeta `animation.frametime` to native texture `frame_time` when binding PNGs on web. PNG import alone can leave native default 1 even if sidecar says 3. Test `TextureAnimator.playAnimationFrame(seconds)` across a frame boundary; 3 ticks means 150 ms/frame. This verifies sampled atlas evaluation, not visible continuous playback.
- Native Java codec omits identity display slots and zero transform components. Compare effective transforms with identity defaults rather than requiring every supplied key to survive serialization.
- Constant texel density does not ensure coherent trim: sampling the same atlas tile origin on differently sized faces can produce broad mismatched highlight bands. Review both front and quarter; use a quiet material swatch or explicitly aligned edge UVs instead of stretching a full tile onto each face.
- Inspect stacked cap/grip surfaces for coplanarity. A tiny brown patch on a metal end cap can be depth fighting, not texture paint: inset the enclosed shaft and give the cap a small deliberate overhang, then compare actual native close-ups. Do not add scratches to hide it.
- Java codec serializes elements in outliner traversal order, which can differ from `Outliner.elements` insertion order after adding a child. Match edited elements by explicit unique name or geometry signature, not array index; index-based checks can falsely pass.
- Keep `texture_size`/editor UV resolution separate from bitmap pixel dimensions. Native codec converts Java 0–16 UV coordinates using editor resolution; avoid double scaling.
- Diagnose layered Java items with temporary native mesh-visibility passes for static sprite plane, animated effect surfaces, and solid cubes. Detached-looking specks can belong to intentional atlas effects, while distant raw `from` coordinates can rotate back onto the model around an offset pivot; inspect transformed bounds before deleting geometry. Do not export diagnostic visibility changes.
- For native animated-texture evidence, `TextureAnimator.playAnimationFrame(seconds)` selects frames according to `frame_time` (ticks, 50 ms each). Read `currentFrame`, capture actual viewport per frame, and preserve `.png.mcmeta` independently; no bone animation is needed for a pulsing core.
- Apply Java single-axis angle restrictions to geometry rotations, not `display` transforms: first/third-person and GUI display rotations legitimately use multiple axes and arbitrary angles.
- Export modified Java JSON with `Codecs.java_block.compile({raw:true})`. Set texture namespace/folder for a new derivative namespace and validate every emitted texture link, sidecar, display transform and PNG dimension. Export editable embedded BBModel separately.
- Treat Nexo/ItemsAdder as pack consumers, not distinct mesh formats. Inspect actual archive paths rather than assuming plugin-specific sources or denying Java JSON support because one folder name is absent.

## Detailed without visual clutter
- User expects rich but orderly detail, not arbitrary extra parts. Establish silhouette first, one primary focal feature, secondary structure and quiet tertiary seams.
- Standardize repeated rail/bracket thickness, spacing and mirrored counterparts. Avoid overlapping coplanar strips, redundant collars, misaligned tips and accidental tangencies.
- Make every brace and ornament visibly supported: seat blade rails in a shared collar and extend cross-braces into their mounts. Parent hierarchy cannot substitute for a visible connection.
- Reserve high contrast for core/hero element. Keep grip bands and minor fasteners subdued; remove scattered texture flecks and use sparse purposeful engraved patterns or wear at contact edges.
- Verify full front, side, three-quarter and thumbnail views plus before/after. Structural validity and cube count are not evidence of attractive detail. Keep previous version intact until comparison is accepted.

## Chunky fish anatomy
- Extend mouth cavity around both cheeks, not only onto front face; split upper cranium and lower jaw volumes so side view reads a bite rather than a sealed box. Stagger short teeth and seat bases into jaw margins.
- Seat side eyes and gill slits flush into cheek geometry; tiny decorative cubes outside narrower rear body often float. Prefer subtle texture clusters over separate scale blocks.
- Read fin taper in the appropriate projection: dorsal and vertical tail from side, paired pectorals from above. Use broad attached roots and narrowing swept steps, not equally narrow stacked towers.
- Use world-aligned UV bands for striped fish so markings cross adjacent body segments coherently; buried decorative band cubes add geometry without visible detail. Keep dorsal spines centered on the body axis and separate from shorter membranes.
- For stepped fin membranes, check both lateral AND vertical overlap: thin slices whose height step exceeds thickness can look connected in render but float. Every segmented ray must intersect its corresponding membrane or neighboring anchored ray.
- For fully axis-aligned cuboid models, a contact graph can detect disconnected parts. This does not prove watertightness or absence of internal overlaps; rotated geometry requires transformed-box checks.

## Native organic mesh studies
- Use `Formats.free`, inspected `Mesh` / `MeshFace` APIs, tapering shared vertex rings and outward-wound triangles for organic silhouette studies when cuboid constraints defeat anatomy. Label Generic mesh studies NOT Java/Nexo item format; do not imply consumer-plugin compatibility.
- Replace a pasted mouth plane with split leading-edge vertices and connected inset walls/back wall when real recess depth is needed. Verify positive triangle areas, edge incidence, per-part vertex connectivity and native front/top/underside views; closed individual parts do not prove the whole animal welded or intersection-free.
- Unwrap curved appendages along ring length and circumference rather than flattening all faces into a top projection. Assert nonzero UV triangle areas; small cap swatches can remove degeneracy but do not establish uniform texel density.
- Compare head close-ups separately from fitted whole-model renders. Intentional head crops may clip wings/tail; only full views must pass unclipped alpha-bound checks. Keep neutral-background composites and native-size thumbnail review.

- Validate closed mesh orientation with positive signed volume per part in addition to positive triangle area and two-face edge incidence. Swapping ring axes or reversing span direction changes winding; these checks catch inverted fins, but do not prove absence of self-intersections.
- Review painted ventral mouth placement in native underside closeups. Valid UV bounds and nonzero UV areas do not prove a marking lands on visible skin; a correct-looking atlas can render as misplaced fragments.
- Check whether another overlapping mesh occludes a painted feature before enlarging its texture marks. Move the UV feature onto exposed skin and render again. Pixel arc connections must preserve bilateral symmetry: one-direction corner filling can produce a heavier asymmetric mouth; derive matching corners from absolute distance to center instead.

- Preserve the explicit keys returned by native `Mesh.addVertices` when grouping vertex rings. Random IDs can be integer-like and JavaScript object enumeration moves them ahead of other keys; `Object.values(imported.vertices).slice(...)` can silently mix rings despite valid manifold geometry. Store key lists or recover rings through topology/coordinates; validate actual paired web/ray centers after native reload.
- Align curved fin ray centerlines with membrane radial stations, then sample intermediate linear spans. Matching analytic camber functions alone is insufficient when tessellation stations differ. Report centerline agreement separately from full tube/web intersection topology.
- For localized fin-edge bowing, apply identical station offsets to paired membrane surfaces and entire corresponding ray rings; taper offsets to zero at roots and endpoints. Verify unchanged anchors, UVs, topology and unrelated elements with an exact native-round-trip diff. Three radial stations still produce an angular mid-span crest, so do not describe a modest silhouette gain as a smooth continuous curve.

## Critique loop
- Inspect silhouette, proportions, pixel density, texture readability, UV stretching, pivot placement, clipping, animation timing and export compatibility.
- Change one concrete weakness, render again, compare evidence. More files or arbitrary palette variants do not demonstrate improvement.
- Recheck apparent gaps from thin low-resolution side views with a native close-up before adding connectors. Dark continuous material can read as background when reduced; use transformed bounds as supplementary evidence, not a substitute for visible surface continuity.
- Confirm part identity before acting on visual critique: vented shins and downward cannons can be confused in crowded kneels. Save a temporary isolated limb/weapon visibility pass, compare native named-part world transforms, and never export diagnostic visibility changes. A reviewer calling a muzzle stationary does not override measured mesh motion.
- Review transition keys after changing a held endpoint: an improved final silhouette can introduce a large late shoulder sweep. Capture matched intermediate front and side views; moving separation earlier can improve front negative space while worsening side overlap. Flat rear-sole orientation also does not prove planting; check its world height before exporting a foot-angle fix.
- With a nearly vertical thigh, local yaw can rotate folded shin/foot presentation without materially moving knee anchor. Compare both yaw signs in front/side/quarter before choosing; clearer foot endpoint is not proof of a wider knee stance. Recheck support bounds across transition, not endpoint alone.
- When seating a held muzzle, measure transformed muzzle minimum-Y while changing arm angles; an elbow-only height minimum can remain above ground. A small shoulder-roll bracket can resolve contact without moving legs. Verify the whole transition for penetration and compare front/side gaps; numerical seating can improve front while tightening side overlap, and does not prove balance.
- Compare endpoint world positions before calling a local elbow rotation a lowering edit. A smaller local X can raise and tuck the hand because parent bones are rotated; preserve front and side evidence, and reject a side-only improvement that destroys the front silhouette.
- When wrapping curved fins with multiple levels of edge/web geometry, ensure radial level multipliers increase monotonically from zero at root to one at tip; non-monotone multipliers invert face winding. Validate winding with directed-edge consistency checks before visual inspection.
- Do not claim visual review if API call times out. Record failure honestly and mark model iteration as structurally checked work-in-progress until neutral render review succeeds.
