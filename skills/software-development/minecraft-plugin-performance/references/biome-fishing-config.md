# CustomFishing biome-only water pools

- Read live loot-conditions.yml, every active contents file, gear effects, and index habitat metadata before changing habitat rules. Item group labels do not restrict catches; loot conditions determine eligibility.
- Keep water pools as sibling groups with explicit, disjoint biome allowlists. Parent lists are additive, so fish in parent/global lists leak into every child. Remove vanilla fallback when strict custom-fish-only water eligibility is required; disclose loss of vanilla random loot.
- Preserve lava subtree and unrelated enchantment/skeleton rules exactly when scope is water-only. Remove lava species from water if restricting them to lava, but retain any existing water species in lava when user exempts lava from changes.
- Inspect actual getNextLoot/getWeightedLoots behavior: ordinary weight-mod only affects already-eligible IDs; weight-mod-ignore-conditions and group-mod-ignore-conditions can introduce absent IDs. Scan all gear/effects for bypasses before claiming habitat enforcement.
- Biome requirements use OTHER_LOCATION with LOCATION fallback. Verify fishing context supplies hook position before explaining boundary behavior. Cave pools should use actual cave biome IDs rather than generic low Y if user requests biome-only fishing.
- Keep species variants together, preserve base weights, and disclose that final probabilities change with pool size. Do not promise unchanged rarity odds merely because raw weights are unchanged.
- Use exact Minecraft version biome names in player-facing habitat text, not invented regional labels such as Danau Hutan. For explicit per-biome requests, use one condition group per namespaced biome ID and provide each biome's eligible fish list. Validate IDs and English names against version-pinned mcmeta registries and assets language data (for example `1.21.11-summary/registries/data.json` and `1.21.11-assets/assets/minecraft/lang/en_us.json`).
- Update custom-data.index-habitat without rewriting item models, price, XP, or player data. Mention lava in labels for species still present in exempt lava pools. Supply exact biome IDs in a companion habitat document when index labels are abbreviated.
- Save local snapshots, validate every fish assignment and biome overlap, compare lava/unrelated branches and all non-habitat item data, and run negative-control misplaced-fish validation. Back up remote originals, upload exact files, read back, plugin-specific reload, then inspect fresh log delta. Distinguish configuration checks and successful reload from actual in-game catch tests.
